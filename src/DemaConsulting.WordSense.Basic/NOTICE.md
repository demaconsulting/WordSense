## The statistical table

The package embeds the table `basic.bin`. It is a derived statistical table: tag n-gram counts, word-tag counts and
context cue statistics. It is computed from counts of the training part of the UD English-EWT treebank (the English Web
Treebank in the Universal Dependencies project). The treebank itself is not part of the package.

- Treebank: UD English-EWT, Silveira et al., Universal Dependencies,
  <https://github.com/UniversalDependencies/UD_English-EWT>.
- License of the treebank: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0),
  <https://creativecommons.org/licenses/by-sa/4.0/>.

`basic.bin` is a derivative of the treebank, and it is shared under the same license, CC BY-SA 4.0. If you redistribute
the table or a table derived from it, you must credit the treebank, link to the license and share your table under the
same license.
