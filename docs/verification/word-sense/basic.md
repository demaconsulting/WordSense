## Basic Subsystem Verification Design

This document describes the verification of the Basic subsystem, the package `DemaConsulting.WordSense.Basic`: a
model that needs no model files and chooses among the analyses (lemma, part of speech and features) of a word with a
statistical part-of-speech tagger and a context cue model, giving every analysis its probability, answering at the part
of speech level and naming a sense only where the selected analysis has one sense (its lemma and part of speech have
exactly one sense).

### Verification Approach

The subsystem is verified through the public `BasicWordSenseModel` and through the internal `BasicClassifier`,
`BasicTables`, `PosTagger`, `CueModel` and `SenseFusion` units. The unit tests use small toy tables built in the test
project in the exact layout the builder writes (`TestTables`) and a toy lexicon, so that every expected result follows
from numbers visible in the test; `BasicTablesTests` also loads the real embedded table. Nothing is mocked: the model
has no files, no network access and no state. Tests in `test/DemaConsulting.WordSense.Basic.Tests`
(`BasicWordSenseModelTests`, `BasicClassifierTests`, `BasicTablesTests`, `PosTaggerTests`, `CueModelTests`,
`SenseFusionTests`) verify the six units, and `XmlDocExampleTests` compiles the XML documentation examples.
`BasicReadmeSampleTests` compiles and runs the README usage sample with the Basic model and compares its code and
output with the README. `ModelTableReadmeTests` checks that the model comparison table of the README equals the table file
generated by the builder (`docs/build_notes/model-table.md`) without loading any model. The accuracy of the shipped
table is measured by the builder (`evaluate basic`) and recorded in the build
notes, not asserted here.

### Test Environment

Standard xUnit v3 runner on net8.0, net9.0 and net10.0. No model files, no network access and no environment variables
are needed.

### Acceptance Criteria

All subsystem scenarios pass on every platform and target framework of the CI matrix, and the unit scenarios of the
`BasicWordSenseModel`, `BasicClassifier`, `BasicTables`, `PosTagger`, `CueModel` and `SenseFusion` units pass.

### Test Scenarios

#### Model Needs No Setup

`EnsureModelAsync` completes immediately without touching the file system or the network, ignores a mirror, and
`ClassifyAsync` returns a working answer at once (see the `BasicWordSenseModel` unit document).

#### Ambiguous Words Are Always Answered

For a word with several analyses the result has details, lists every analysis with its probability (the probabilities
sum to one, the lemmas and parts of speech by the sum of their probabilities with the largest first, a tie in lexicon
order), has the level part of speech and a confidence between one over
the number of lemmas and parts of speech and 1; the model never abstains (see the `BasicClassifier` and `SenseFusion`
unit documents).

#### Context Chooses the Part of Speech

The same word is a noun after a determiner and a verb after a pronoun, because the tagger weighs the whole sentence
(see the `PosTagger` and `BasicClassifier` unit documents). A modal or primary auxiliary (`we will record`, `she is
here`) is answered `Auxiliary`, while `his last will and testament`, `the can is empty` and `the will` stay nouns:
the Auxiliary analysis is not chosen directly after an article or possessive.

#### Cues Separate Analyses of One Part of Speech

Analyses that share a part of speech, such as the past and the present of `read` or the lemmas of `left`, are told
apart by the words around the target (see the `CueModel`, `SenseFusion` and `BasicClassifier` unit documents).

#### Answer Level Is Stated Honestly

An ambiguous word is answered at the part of speech level without a group or sense id, with all its analyses listed and
no scored senses; a word whose selected analysis has a lemma and part of speech with one sense is answered at the sense
level with that sense (and lists it with probability 1 in its analysis); a word with one analysis and several senses is
answered at the part of speech level with confidence 1, and an unknown word at the level none with no analysis; no
answer is at the group level (see the `BasicClassifier` unit document).

#### Unambiguous Words Match the Other Packages

A word with a single analysis and a single sense is answered with the analysis, the sense (with no group) and confidence
1, and an unknown word is not known, has no analyses, no details, the level none and confidence 0, exactly as in the
model packages. A number word such as `one` has details.

#### Embedded Table Is Valid

The table embedded in the assembly loads and a malformed table, a table built for another analysis inventory and a table
with an unknown or duplicate analysis are rejected with `InvalidDataException` (see the `BasicTables` unit document).

#### Deterministic and Thread-Safe

The same words give the same results every time, also from many threads at once (see the `BasicClassifier` and
`BasicWordSenseModel` unit documents).

#### XML Documentation Examples Compile

Every `<code>` example of the shipped XML documentation file is extracted and compiled against the real public API
(`XmlDocExampleTests`).
