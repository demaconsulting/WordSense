### WordPieceTokenizer Verification

#### Verification Approach

Tests in `test/DemaConsulting.WordSense.Onnx.Tests/WordPieceTokenizerTests.cs` compare the tokenizer with a fixture of
cases generated from the reference Hugging Face tokenizer for the uncased vocabulary (MiniLM), test the cased setting
with a small hand-built cased vocabulary, and test other small hand-built vocabularies. The fixture is generated by
`tools/tokenizer-fixture` and copied to the test output as `Fixtures/tokenizer-parity.json`. No mocking is needed.

#### Test Environment

Standard xUnit v3 runner. The fixture file is committed test data; the parity scenario reads the MiniLM vocabulary
through `ModelAssets` (skipped when the Git LFS content is absent). No network access.

#### Acceptance Criteria

All scenarios below pass on every platform and target framework of the CI matrix.

#### Test Scenarios

- **WordPieceTokenizer_Tokenize_Fixture_MatchesReferenceTokenizer**: ids and offsets equal the reference for every
  case of the uncased fixture (accents, emoji, CJK, punctuation, long words, apostrophes).
- **WordPieceTokenizer_Tokenize_CasedVocabulary_KeepsCase** and
  **WordPieceTokenizer_Tokenize_UncasedVocabulary_LowerCases**: the cased setting keeps case and accents, the uncased
  setting lower-cases the text.
- **WordPieceTokenizer_Tokenize_SmallVocabulary_SplitsIntoWordPieces**: greedy longest match with `##`.
- **WordPieceTokenizer_Tokenize_EmptyText_ReturnsNoTokens**: empty text gives no tokens.
- **WordPieceTokenizer_TokenizeWords_ReturnsPieceRangePerWord** and
  **WordPieceTokenizer_TokenizeWords_NoWords_ReturnsNoTokens**: the piece range of each word of a word list.
- **WordPieceTokenizer_BuildWindow_ShortText_ContainsWholeText**: short input is framed by the class and separator
  tokens.
- **WordPieceTokenizer_BuildWindow_LongText_KeepsTargetInsideWindow**: long input is windowed around the target.
- **WordPieceTokenizer_BuildWindow_TargetLongerThanCapacity_ClipsTargetToWindow**: a target longer than the window
  capacity is clipped to the window.
- **WordPieceTokenizer_NullArguments_ThrowArgumentNullException**: null vocabulary, text, word list and word are
  rejected.
- **WordPieceTokenizer_VocabularyMissingSpecialToken_ThrowsArgumentException**: a vocabulary without `[UNK]`, `[CLS]` or
  `[SEP]` is rejected.
- **WordPieceTokenizer_Tokenize_LoneSurrogatesAndControlCharacters_AreDropped**: lone surrogates and control characters
  are dropped.
- **WordPieceTokenizer_Tokenize_OverlongWord_BecomesSingleUnknown**: a word of 100 normalized characters is split into
  pieces and one of 101 becomes a single `[UNK]` spanning the word.
- **WordPieceTokenizer_FromFile_ReadsLinesAndReportsIoErrors**: a vocabulary file with mixed line endings is read line
  by line and a missing file raises an `IOException`.
