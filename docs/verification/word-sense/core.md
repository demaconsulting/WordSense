## Core Subsystem Verification Design

This document describes the verification of the core subsystem, the package `DemaConsulting.WordSense` in the
namespace `DemaConsulting.WordSense`: the embedded word lexicon, the sense catalog, the contracts that every model
implements and the built-in statistical model (the Basic model, formerly a package of its own), which chooses among the
analyses (lemma, part of speech and features) of a word with a statistical part-of-speech tagger and a context cue
model, giving every analysis its probability, answering at the part of speech level and naming a sense only where the
selected analysis has one sense (its lemma and part of speech have exactly one sense).

### Verification Approach

The lexicon, the catalog and the contracts are verified through the public API with the embedded lexicon and catalog.
No model, fake or file is needed: the contracts are plain types and interfaces, and the lexicon and catalog are read
from the assembly resource. Tests in `test/DemaConsulting.WordSense.Tests` (`WordLexiconTests`, `ContractsTests`,
`FallbackWordSenseModelTests`, `WordSenseExceptionTests`)
verify the units `WordLexicon` and `WordSenseContracts`. The boundary to the encoder packages is verified by those
packages themselves, which implement the contracts.

The statistical model is verified through the public `BasicWordSenseModel` and through the internal `BasicClassifier`,
`BasicTables`, `PosTagger`, `CueModel` and `SenseFusion` units. The unit tests use small toy tables built in the test
project in the exact layout the builder writes (`TestTables`) and a toy lexicon, so that every expected result follows
from numbers visible in the test; `BasicTablesTests` also loads the real embedded table. Nothing is mocked: the model
has no files, no network access and no state. `BasicWordSenseModelTests`, `BasicClassifierTests`, `BasicTablesTests`,
`PosTaggerTests`, `CueModelTests` and `SenseFusionTests` verify the six units. `BasicReadmeSampleTests` compiles and runs
the README usage sample with the Basic model and compares its code and output with the README. `ModelTableReadmeTests`
checks that the model comparison table of the README equals the table file generated by the builder
(`docs/user_guide/model-table.md`) without loading any model. The accuracy of the shipped table is measured by the
builder (`evaluate basic`, `evaluate-tagger`) and recorded in the model comparison table and the accuracy chapter of the
user guide (`docs/user_guide/model-table.md`, `docs/user_guide/accuracy.md`), not asserted here.

`XmlDocExampleTests` compiles the XML documentation examples of the package against the public API.

### Test Environment

Standard xUnit v3 runner on net8.0, net9.0 and net10.0. No model files, no network access and no environment variables
are needed.

### Acceptance Criteria

All subsystem scenarios pass on every platform and target framework of the CI matrix, and the unit scenarios of the
`WordLexicon`, `WordSenseContracts`, `BasicWordSenseModel`, `BasicClassifier`, `BasicTables`, `PosTagger`, `CueModel`
and `SenseFusion` units pass.

### Test Scenarios

#### Lexicon Loads and Serves Known Words

The embedded lexicon holds entries for common lemmas and their inflected forms; a form that belongs to several lemmas
or tenses, such as `read`, lists one analysis for each, and a word with one analysis lists one. The scenarios are
detailed in the `WordLexicon` unit document.

#### Sense Catalog Resolves Senses and Groups

The senses of a lemma and part of speech are listed in the order of Open English WordNet (project senses last); a sense
is found by its readable id and by its
OEWN sense key (the same sense through either), a project sense has no key, and every sense is in at most one group
that lists it, every group having at least two senses and never all the senses of its lemma and part of speech, and
every group id carrying the group marker (`lemma#group:label`) and never equal to a sense id; the version string of the
inventory is the same on every call and has the form of 16 lower-case hexadecimal digits. The
scenarios are detailed in the `WordLexicon` unit document.

#### Every Answer Has One Stable Key

The key of a result (`ClassifyResult.Key`) is derived from the result alone: null for an unknown word and for a result
without a selected analysis, otherwise (every known answered word) the
normalized spelling, the lemma, the part of speech, the features and, where the answer or the ranking names a sense, its
label. `WordKey.TryParse` reads a key back (canonical text only), and `WordLexicon.Keys()` lists every key that any model
can return, each once, in a fixed order, with deferred execution after one pass over the spellings. The guarantee that
the list holds every key of every model holds by construction (the key of a result and the list are built from the same
analyses and catalog senses); the keys the three models give for the words of the reviewed suite and of a sample of
corpus sentences are all in that list, which is a sample verification of it. The scenarios
are detailed in the `WordSenseContracts` and `WordLexicon` unit documents.

#### Contracts Are Usable Without a Model Package

`ClassifyResult`, `AnalysisCandidate`, `SenseCandidate`, `SenseLevel`, `WordDetails`, `PartOfSpeech`, `SenseInfo`,
`SenseGroup`, `DownloadOptions`, `IWordSenseModel`, `IDownloadableWordSenseModel`, `FallbackWordSenseModel` and the
typed exceptions can be used by a test double with no
model package referenced (`ContractsTests`, `FallbackWordSenseModelTests`, `WordSenseExceptionTests`). A model that has
files offers the optional capability `IDownloadableWordSenseModel`, which extends `IWordSenseModel` with
`EnsureModelAsync`; the model contract itself only classifies, and a caller that holds it reaches the capability with a
type check. The scenarios are
detailed in the `WordSenseContracts` unit document.

#### No ONNX Dependency

The package does not reference ONNX Runtime or any other WordSense package; the automated test
`WordSenseContracts_CoreAssembly_HasNoOnnxOrWeightsReferences` (`ContractsTests`) checks the assembly references, and it
is why the core test project runs without model files.

#### Model Needs No Setup

The statistical model has no preparation step: `BasicWordSenseModel` does not implement `IDownloadableWordSenseModel`
(`BasicWordSenseModel_IsNotDownloadable`) and `ClassifyAsync` returns a working answer at once, without any call before
it (see the `BasicWordSenseModel` unit document).

#### Failures Are Typed

The core defines the abstract `WordSenseException` and the sealed `ModelUnavailableException`,
`ModelIntegrityException` and `DownloadConfigurationException`, each keeping the original exception as inner exception
(`WordSenseExceptionTests`, see the `WordSenseContracts` unit document). A missing or damaged embedded resource, the
word image and sense catalog of the lexicon or the statistics table of the built-in model, is reported as
`ModelIntegrityException` carrying the original `InvalidDataException` (see the `WordLexicon` and `BasicTables` unit
documents; `WordSenseExceptions_Hierarchy_DerivesFromWordSenseException`,
`WordLexicon_OpenImage_MissingResource_ThrowsModelIntegrity` and
`BasicTables_LoadEmbedded_MissingResource_ThrowsModelIntegrity` verify the subsystem requirement).

#### Ambiguous Words Are Always Answered

For a word with several analyses the result has details, lists every analysis with its probability (the probabilities
sum to one, the lemmas and parts of speech by the sum of their probabilities with the largest first, a tie in lexicon
order), has the level part of speech and a confidence between one over
the number of lemmas and parts of speech and 1; the model never abstains (see the `BasicClassifier` and `SenseFusion`
unit documents).

#### Context Chooses the Part of Speech

The same word is a noun after a determiner and a verb after a pronoun, because the tagger weighs the whole sentence
(see the `PosTagger` and `BasicClassifier` unit documents). A modal or a helper (`we will record`, `she is running`)
is answered `Auxiliary`, a form of `be` that is the main verb of its clause (`she is here`) is answered `Verb` (the
open corpus the statistics come from, like the lexicon, treats the copula as a main verb), while `his last will and
testament`, `the can is empty` and `the will` stay nouns: the Auxiliary analysis is not chosen directly after an article
or possessive.

#### The Clause of a Word Weighs Its Part of Speech

Through the public `BasicWordSenseModel`, the tagger knows whether the clause of a word already has a verb. A word that
could be a noun or a verb and follows a determiner and a noun is a noun in a clause that already has a verb
(`BasicWordSenseModel_ClassifyAsync_NounAfterNounInClauseWithVerb_IsNoun`: `Please open the door handle`, `Replace the
oil filter`, `Inspect the brake pad`), and is a verb again after a comma or a conjunction that starts a new clause
(`BasicWordSenseModel_ClassifyAsync_VerbAfterClauseBreak_IsVerb`: `He nodded , the pump runs`, `He nodded and the pump
runs`, where the same sentence without the break reads `runs` as a noun). The clause counts, their smoothing and the
transitions are verified in the `BasicTables` and `PosTagger` unit documents.

#### A Gerund at the Start Does Not Take the Verb of the Clause

Through the public `BasicWordSenseModel`
(`BasicWordSenseModel_ClassifyAsync_GerundAtTheStart_IsStillAVerb`), a first word that the dictionary lists as a verb
only as a gerund (`Resolving this issue requires care`, `Checking this valve takes time`) is answered `Verb`, because the
clause has no verb yet and the noun-phrase reading of the opening words is not favored. The decision reads the
dictionary, not the ending, in the `BasicClassifier` unit document and is applied in the `PosTagger` unit document.

#### A Possessive Written as One Token Is Read as Stem and Marker

Through the public `BasicWordSenseModel`
(`BasicWordSenseModel_ClassifyAsync_PossessiveToken_ReadsTheNextWordAsNoun`), the word after a possessive that is one
token (`the sergeant's rank`, `the pilot's license`, `the captain's order`) is a noun, as after a noun and a separate
marker, while the possessive itself is answered as one token with its own noun analysis. The expansion and the rows of
the caller are verified in the `PosTagger` and `BasicClassifier` unit documents.

#### Cues Separate Analyses of One Part of Speech

Analyses that share a part of speech, such as the past and the present of `read` or the lemmas of `left`, are told
apart by the words around the target (see the `CueModel`, `SenseFusion` and `BasicClassifier` unit documents).

#### The Case of the Word Chooses the Lemma

Through the public `BasicWordSenseModel` (`BasicWordSenseModel_ClassifyAsync_CaseOfWord_ChoosesTheLemma`), a spelling
that has a capitalized and a lower-case lemma is answered with the lemma of the written case: `Polish` in `My neighbor
speaks fluent Polish and a little German` is the language and `polish` in `The shop sells silver polish in small tins`
the shine, `August` in `We usually take our vacation in August` is the month and `august` in `The old professor had an
august presence` the adjective. The rules of the case evidence (what counts as isolated, a run, the start of a sentence)
are verified in the `BasicClassifier` unit document.

#### The Tense of a Verb Follows Its Context

Through the public `BasicWordSenseModel` (`BasicWordSenseModel_ClassifyAsync_SameSpellingVerb_TenseFollowsTheContext`),
a verb whose past and non-past share a spelling is answered with the tense that its context says: `I will read that
tomorrow` and `Please put the books on the shelf` select a non-past analysis, `I have read that already` and `She had
put the keys in her bag` a past one, with the probabilities of the word summing to one. The split of the slot by the
shared tense table is verified in the `BasicClassifier`, `CueModel` and `BasicTables` unit documents.

#### A Verb-Dominant Word Ending a Compound Is a Noun

Through the public `BasicWordSenseModel` (`WordSenseCore_Tagger_VerbDominantWordEndingACompound_IsNoun`, in
`ContractsTests`), a word that is mostly a verb is answered as a noun when it follows a determiner and a modifier noun:
`call` in `Make a courtesy call to the hotel .` and `sweep` in `Do a safety sweep of the room .`. The shift between the
noun slot and the verb slot by the shared noun/verb table is verified in the `BasicClassifier`, `CueModel` and
`BasicTables` unit documents, and the retirement of the format `WSB6` in the `BasicTables` unit document.

#### Composite Model Answers Each Word with One Model

`FallbackWordSenseModel` answers a word with the result of the primary model when it scored senses for it and with the
result of the fallback model otherwise (`FallbackWordSenseModel_PrimaryScoredSenses_UsesPrimary`,
`FallbackWordSenseModel_PrimaryChoseOnlyAnalysis_UsesFallback`); senses that a primary model only ranks by usage
(`SensesRankedByUsage`, as the Basic model does) are not scored senses, so a Basic primary result is never refined or
reconciled (`FallbackWordSenseModel_BasicAsPrimary_UsageRankedSenses_AreNotRefinedOrReconciled`,
`FallbackWordSenseModel_PrimaryWithContextScoredSenses_StillReconciled`); the variants of a slot that the primary model
gives the
same probability take the proportions of the fallback and keep the probability of the slot
(`FallbackWordSenseModel_TiedVariantsOfASlot_TakeTheProportionsOfTheFallback`).

Through the public composite model with the built-in Basic model as its fallback
(`WordSenseCore_Fallback_PartOfSpeechLevelPrimary_IsReconciledWithTheBasicModel`, in `ContractsTests`), a primary model
that answers the word `use` at the part-of-speech level with the noun at 0.9 and the verb at 0.1 gives, for "Do not use
these guys ." and a primary weight of 0.3, the verb analysis selected by the Basic tagger at the part-of-speech level
with the probabilities summing to one, while the primary weight 1 keeps the noun and the words that the primary model
does not know are answered exactly as the Basic model answers them. The combination itself (the product of the powers,
the floor, the union of the slots, the variants and senses kept, the sense and group answers left alone) is verified in
the `FallbackWordSenseModel` scenarios of the `WordSenseContracts` unit document. The composite also prepares the
members that can be prepared, only those, and reports a failure after all ran
(`FallbackWordSenseModel_EnsureModelAsync_EnsuresBoth`, `FallbackWordSenseModel_EnsureModelAsync_OnlyCapableMemberEnsured`),
and disposes both models once (`FallbackWordSenseModel_Dispose_DisposesBothOnce`). The scenarios are detailed in the
`WordSenseContracts` unit document.

#### Reviewed Suite Does Not Regress

The Basic model answers the 364 sentences of the reviewed suite (`corpus/suite`) at least as well as the expectation file
records for it: no row falls below its expectation (`fine`, `answer` or `miss`), so a regression fails the build while
the known misses (the heteronym rows that need a sense, which Basic ranks only by usage) stay documented
(`BasicSuiteTests`, `BasicSuite_ExpectedPasses_StillPass`).

#### Answer Level Is Stated Honestly

An ambiguous word is answered at the part of speech level without a group or sense id, with all its analyses listed and
the senses of its analyses ranked by the usage prior when they are several (never an answer); a word whose selected
analysis has a lemma and part of speech with one sense is answered at the sense
level with that sense (and lists it with probability 1 in its analysis); a word with one analysis and several senses is
answered at the part of speech level with confidence 1, and an unknown word at the level none with no analysis; no
answer is at the group level (see the `BasicClassifier` unit document).

#### Unambiguous Words Match the Other Packages

A word with a single analysis and a single sense is answered with the analysis, the sense (with no group) and confidence
1, and an unknown word is not known, has no analyses, no details, the level none and confidence 0, exactly as in the
encoder packages. A number word such as `one` has details.

#### Embedded Table Is Valid

The table embedded in the assembly loads and a malformed table, a table built for another analysis inventory and a table
with an unknown or duplicate analysis are rejected with `InvalidDataException` when read from a stream; a missing,
corrupt or foreign embedded table is reported as `ModelIntegrityException` carrying that `InvalidDataException` (see the
`BasicTables` unit document).

#### Deterministic and Thread-Safe

The same words give the same results every time, also from many threads at once (see the `BasicClassifier` and
`BasicWordSenseModel` unit documents).

#### XML Documentation Examples Compile

Every `<code>` example in the shipped XML documentation file (`DemaConsulting.WordSense.xml`, which now also covers the
statistical model) is extracted and compiled against the real public API, so a documented example cannot drift from the
API (`XmlDocExampleTests`).
