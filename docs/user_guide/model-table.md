# Model Comparison Table

This file is generated by `WordSense.Builder evaluate <model>`, `evaluate-running` and `evaluate-senses` with
`--table docs/user_guide/model-table.md`; every command writes the columns it measures and keeps the others.
Do not edit it by hand: the table of the root README must equal the table below (a doc-test checks it).

The size, memory, latency and first-use columns are machine dependent: they come from the last `evaluate` run and
are to be remeasured on a quiet machine when a model changes. The chapter "Accuracy and Model Choice" explains the
measurement conditions and how to read the columns.
