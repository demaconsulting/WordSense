# Model comparison table

This file is generated by `WordSense.Builder evaluate <model>`, `evaluate-running` and `evaluate-senses` with
`--table docs/build_notes/model-table.md`; every command writes the columns it measures and keeps the others.
Do not edit it by hand: the table of the root README must equal the table below (a doc-test checks it).

The size, memory, latency and first-use columns are machine dependent. They were remeasured for the final increment (I6)
with nothing else heavy running: an Intel Core i7-13850HX laptop (20 cores, 28 threads, 64 GB RAM, Windows 11
Enterprise 10.0.26100, the Balanced power scheme, the machine idle at 1 to 7 percent CPU before and between the runs),
the builder in the Release configuration on .NET 10.0.12 with ONNX Runtime on the CPU (2 intra-op threads), one
sentence at a time. Three repeated `evaluate` runs of each model agreed within 1 percent in the latency (MiniLM 1.52 to
1.54 ms, BERT 8.05 to 8.13 ms, Basic 0.11 ms), within 3 percent in the model part of the first use (MiniLM 443 to
452 ms, BERT 684 to 698 ms) and within 2 MiB in the memory; the table shows the first run. Another machine will give
other values, so read the columns as the order of magnitude and the ratio between the models, not as a guarantee.
