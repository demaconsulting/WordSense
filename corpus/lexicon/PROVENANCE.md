## Command (historical)

The committed `lexicon.tsv` was produced once by an importer (`import-moby`) that has since been removed from
`WordSense.Builder`; the raw Moby file is not committed, so the file is not regenerated by the build. The command that
produced it was:

```text
dotnet run --project tools/WordSense.Builder -- import-moby --input mobypos.txt \
  --output corpus/lexicon/lexicon.tsv
```

The importer read `corrections.tsv`, `classes.tsv` and `morphology.tsv` from the directory of the output. The
`words` command of the builder reads the committed `lexicon.tsv`.

## Filter Rules (as applied by the importer)

1. The input is read as Latin-1; entries are separated by line feeds and read `word\codes`.
2. Only single lower-case words of the letters `a-z` are kept (no spaces, hyphens, digits or capitals).
3. A word with a determiner, article or numeral code (`D`, `I`, `o`) is dropped: determiners stay unknown.
4. Codes map to parts of speech: `N`, `h` and `p` noun; `V`, `t` and `i` verb (`V` is the ordinary verb flag);
   `A` adjective; `v` adverb; `r` pronoun; `P` preposition; `C` conjunction; `!` interjection.
   A word without a mappable code is dropped.
5. A word that is only an adjective and ends in `-ed` or `-ing` is adjective and verb.
   An `-ing` word of five or more letters without a verb code gains the verb sense when its stem
   (plain, plus `e`, or without a doubled final consonant) has a verb code.
6. The corrections replace the set of a word.
7. The class gate holds back the classes that failed the precision gate: a word whose every part of speech is
   held back is not emitted (it is listed in `gated.tsv` for the evaluation).

The output letters are N noun, R pronoun, V verb, J adjective, B adverb, P preposition, C conjunction and I
interjection, in this order within a word.
